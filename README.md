# TargiX Homebrew tap

```bash
brew install --cask targix/tap/vibevac
```

| Cask | What it is |
| --- | --- |
| [`vibevac`](Casks/vibevac.rb) | [VibeVac](https://github.com/TargiX/vibevac), a local macOS app that safely reclaims rebuildable storage from AI coding workspaces and Git worktrees. |

The cask is updated automatically when a VibeVac release is published.
